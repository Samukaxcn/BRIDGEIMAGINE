# BRIDGEIMAGINE

Aplicativo desktop independente para organizar fotografias locais.

## Download para Windows

Baixe o pacote ZIP na [seção Releases](https://github.com/Samukaxcn/BRIDGEIMAGINE/releases), extraia e execute BRIDGEIMAGINE.exe.

A versão inicial oferece miniaturas, estrelas, rótulos, tela cheia (Espaço), revisão (Ctrl+B) e renomeação sequencial em lote. Na revisão, baixo retira apenas da seleção e cima restaura; os arquivos continuam na pasta.

Testado em Linux com Electron real; execução no Windows ainda requer validação. O pacote não é assinado digitalmente. Classificações são mantidas no catálogo local, sem integração XMP. Ainda não inclui todas as funções do Adobe Bridge.

Implementação própria, sem executáveis, DLLs ou recursos gráficos do Adobe Bridge.
